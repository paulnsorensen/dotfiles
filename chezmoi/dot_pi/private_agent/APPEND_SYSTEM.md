# Pi addendum

Use `~/.pi/agent/AGENTS.md` for global preferences and each repository's instructions for project rules.

- Use native file tools for file operations and Bash for commands.
- Use Tilth direct tools for structural source work.
- Use the MCP proxy for other configured MCP servers.
- Use `web_search` and `fetch_content` for current external evidence.
- Delegate only work that benefits from a fresh context or parallel execution.
- Give each subagent a bounded task, explicit tools, and a verification target.
